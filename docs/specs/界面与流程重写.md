# Spec · 界面与流程重写

状态：第一批（框架 + ① 上传 + ② 免费拆解，PR #10）、第二批（③ Key 引导 + 内容拆解 + 首页，PR #11）已实现 ｜ 优先级：P1 ｜ 设计稿：Claude Design 画板「爆款复刻工作台 · 交互与界面重设计」

## 为什么要做

现在的界面有三个实质问题，不是审美问题：

1. **Key 墙堵在最前面。** 用户还没拿到任何东西，就被要求填 Key、充值。转化卡在这里。
2. **五个阶段挤在一页长滚动。** 用户不知道现在该干哪一步、下一步是什么。
3. **「旧流程（过渡用，新流程做完后删除）」还露在用户面前。** 开发中间态暴露给了终端用户。

另外术语是开发者语言：「多模态模型」「逐词转录」「切点检测与帧网格」「整段视频发给 Gemini（实验）」——面向的是实体店老板。

## 目标

- 免费拆解前置，Key 墙后移到复刻入口
- 阶段式导航替代单页长滚动
- 术语改成商户听得懂的话
- 花钱的动作在界面上一眼可辨

## 不做

- 不换前端框架。现有是 5567 行原生 JS + 纯 CSS，由 Python 起服务；引 React/antd 等于整体重写，还会把 8MB 的代码更新通道撑爆，不值。
- 不改配色体系。现有 `--accent: #2f6f55` / `--pay: #b2363f` 这套是好的，继续用。

## 设计

### 四阶段与那条分界线

```
① 上传素材 → ② 免费拆解  ‖ 这之后才要 Key ‖  ③ 内容拆解 → ④ 复刻成片
```

顶部导航常驻，已完成打勾、当前高亮、未解锁带锁图标。②和③之间画一条虚线分界，旁边一行小字。

### 免费层的真实边界

`06 pack`（7 卡拆解包）依赖 04/05 两步大模型，**做不进免费层**。所以：

| 层 | 交付什么 |
|---|---|
| 免费 | 媒体信息、逐词字幕（可导 SRT）、镜头切点与缩略图、拍摄方式判定 |
| 付费 | 整片理解、逐段细读、7 卡拆解包、选角换品、生图成片 |

免费层的产出要做成一份能独立交付的报告——不填 Key 走人也是一个体面的结局。

### Key 引导

不是干巴巴「请先填 Key」。在 ③ 的入口给一张解释卡：为什么需要、三个渠道怎么选、能管到哪几步、费用怎么算、Key 存在哪。

三个渠道页签：ViralTok（推荐，一个 Key 通吃）、豆包方舟（国内直连，生图要另配）、已有 Key（OpenAI / Claude / DeepSeek）。

Claude 那一项要在界面上写明**不出图也不出视频**，那两步仍走原渠道。`DEFAULT_ROUTES` 本来就是分步路由、支持 `follow:` 继承，这是现成能力。

### 术语对照

| 现在 | 改成 |
|---|---|
| 多模态模型 | 会读片子的模型 |
| 逐词转录 | 识别台词 |
| 切点检测与帧网格 | 切分镜头 |
| 取证 | 认拍摄方式 |
| 整段视频发给 Gemini（实验） | 收进高级设置或直接去掉 |

### 费用可见

所有会产生费用的按钮带红点，顶部常驻「本项目已用 ¥X」，点下去之前再确认一次。

### 渠道图标

用 `lobehub/lobe-icons`（MIT）补 OpenAI / Claude / DeepSeek / 豆包的图标，不要自己画。
