# 登录搜索与视频列表

## 需求

改掉「只在 Tab 里嵌平台官方页」的做法。用户在抖音、小红书已经登录后，用这个登录态在后台搜索相关行业视频，并在工作台里用我们自己的列表展示。

本切片最小可验收范围：

- 平台先做抖音、小红书。B站先保持原入口，不在本切片做列表。
- 用户主动搜索或点行业词后才去搜，不在后台持续刷、不批量爬未请求的内容。
- 没有平台官方接口，只使用应用内已登录会话，读取搜索结果页上当时能看到的条目。读不到的字段留空，不编造。
- 未登录时仍先「去登录」；登录成功后，若刚才有未完成的搜索，自动按原词搜一次并出列表。

已知限制（必须写在实现和说明里，不向用户假装成官方接口）：平台改版可能导致取数失败；取数依赖用户登录后的可见结果。失败时给明确原因和重试，不要空白卡住。

## 设计

### 首页结构

- 保留「找同行的爆款」、平台 Tab（本切片内「抖音」「小红书」出列表，「B站」可提示本切片未改）、城市、关键词、行业词、分享链接。
- Tab 下不再嵌入该平台的完整网站。已登录且完成一次搜索后，展示我们自己的结果列表。尚未搜索时，显示简短空态：提示输入关键词或点行业词。
- 未登录：不展示列表，只出说明和「去登录」。登录判定仍偏保守，不准时当成未登录。
- 这样不再出现「工作台外层和平台页抢滚动」。列表在我们自己的页面里滚动。

### 搜索与取数

- 触发：点「去找爆款」、点行业词、或已登录后自动补跑刚才的搜索。
- 词的规则与现在一致：城市可空，关键词或行业词必填；有城市则与关键词一起用于搜索。
- 使用现有应用内登录会话去打开该平台的搜索结果（用户不必再看到这张平台搜索页），把当前能看到的结果收成列表后展示。一次只搜当前 Tab 的这一个平台。
- 本切片先出第一页结果。若结果页还能继续加载，可提供「加载更多」；做不到就先第一页，并在空态或列表底部说明目前只展示这一批。
- 进行中：列表区显示「正在搜索…」，不打断顶部操作区。失败：说明失败原因，提供重试，保留原搜索词。

### 列表与操作

每条结果尽量展示：封面、标题、作者、当时能读到的播放或点赞数据、来源平台。缺项就省略，不填假数据。

- 点一条：进入这条的详情（可用我们自己的详情区打开该视频页，或打开该条链接对应内容），从详情可以返回列表，列表位置保留。
- 「同款复刻」可在列表条目或详情上操作，效果与现在一致：为这条视频建项目并进入该项目。不要让用户再回到平台网站里找播放器再点。
- 分享链接仍可粘贴打开：能识别到对应平台且已登录时，把这条作为结果打开（进入详情或作为列表中的一项再进入）；未登录则先登录再打开。

### 软件更新

本切片不包含软件更新弹层。那一条仍按《首页改版-真机体验》的 T1 单独修。

## 任务清单
