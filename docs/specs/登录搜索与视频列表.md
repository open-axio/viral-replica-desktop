# 登录搜索与视频列表

## 需求

改掉「只在 Tab 里嵌平台官方页」的做法。用户在抖音、小红书已经登录后，用这个登录态在后台搜索相关行业视频，并在工作台里用我们自己的列表展示。

本切片最小可验收范围：

- 平台先做抖音、小红书。B站先保持原入口，不在本切片做列表。
- 首页分类做成三级：一级是平台（抖音、小红书），二级和三级是下面锁定的行业分类。不含「短剧获客」。
- 已登录对应平台后，选中一个三级分类即在后台按该分类搜索，结果用我们自己的列表展示。用户主动搜索或点分类后才去搜，不在后台持续刷、不批量爬未请求的内容。
- 没有平台官方接口，只使用应用内已登录会话，读取搜索结果页上当时能看到的条目。读不到的字段留空，不编造。
- 未登录时仍先「去登录」；登录成功后，若刚才有未完成的搜索或已选分类，自动按原条件搜一次并出列表。

已知限制（必须写在实现和说明里，不向用户假装成官方接口）：平台改版可能导致取数失败；取数依赖用户登录后的可见结果。失败时给明确原因和重试，不要空白卡住。

## 设计

### 首页结构

- 保留「找同行的爆款」。本切片内一级分类是平台 Tab：「抖音」「小红书」出列表，「B站」可提示本切片未改。城市、关键词、分享链接保留。
- 原「行业词」入口改成二级、三级分类条，不再用零散标签。
- Tab 下不再嵌入该平台的完整网站。已登录且完成一次搜索后，展示我们自己的结果列表。
- 未登录：不展示列表，只出说明和「去登录」。登录判定仍偏保守，不准时当成未登录。
- 列表在我们自己的页面里滚动，不再出现「工作台外层和平台页抢滚动」。
- 列表用双列卡片：封面、当时能读到的时长、标题、主按钮「同款」。缺项就省略，不填假数据。作者、播放或点赞数据能读到就作为次要信息展示。

### 锁定的二级、三级分类

二级固定为下面 8 项，顺序不变。三级从属于对应二级，顺序不变。本切片不得增减或改名。

- 本地生活：餐饮美食、酒店民宿、门店零售、宠物服务、汽车服务
- 电商带货：服饰鞋包、美妆个护、数码家电、家居日用
- 美业健康：美容护肤、健身瑜伽、养生理疗、美发美甲
- 知识教育：课程招生、读书讲座、少儿兴趣
- 房产家装：房产中介、装修公司
- 穿搭美妆：穿搭分享、美妆好物
- 生活旅行：旅行出片、居家美食、萌宠日常
- 运动健身：健身打卡

交互：

- 点二级后，只展示该二级下的三级；点三级后即按该三级名称搜索（有城市则与城市一起用于搜索）。
- 二级下只有一个三级时（目前仅「运动健身 / 健身打卡」），点二级等同选中该三级并搜索。
- 进入已登录的「抖音」或「小红书」Tab 时，默认选中「本地生活 / 餐饮美食」并自动搜一次，避免空白。尚未登录时只展示分类和「去登录」，不搜。
- 切换一级（平台）时，保留当前选中的二级、三级，并按新平台重新搜索（已登录时）。
- 用户仍可在关键词框输入后点「去找爆款」搜索；关键词搜索与分类搜索互斥时，以最后一次触发为准，并在列表区体现当前用的是关键词还是哪个分类。

### 搜索与取数

- 触发：点三级分类（含默认自动选中）、点「去找爆款」、或已登录后自动补跑刚才的搜索或已选分类。
- 使用现有应用内登录会话去打开该平台的搜索结果（用户不必再看到这张平台搜索页），把当前能看到的结果收成列表后展示。一次只搜当前 Tab 的这一个平台。
- 本切片先出第一页结果。若结果页还能继续加载，可提供「加载更多」；做不到就先第一页，并在空态或列表底部说明目前只展示这一批。
- 进行中：列表区显示「正在搜索…」，不打断顶部操作区。失败：说明失败原因，提供重试，保留原分类或搜索词。

### 列表与操作

- 点一条：进入这条的详情（可用我们自己的详情区打开该视频页，或打开该条链接对应内容），从详情可以返回列表，列表位置保留。
- 「同款」可在列表卡片或详情上操作，效果与现在的「同款复刻」一致：为这条视频建项目并进入该项目。不要让用户再回到平台网站里找播放器再点。
- 分享链接仍可粘贴打开：能识别到对应平台且已登录时，把这条作为结果打开（进入详情或作为列表中的一项再进入）；未登录则先登录再打开。
- 列表区适应剩余高度并分页：列表区（工具栏以下的结果容器）占满到「自己放一条视频进来」「最近的项目」之上的剩余窗口高度。这两块钉在窗口底部，不被列表顶出屏幕。窗口拉伸、缩放后立刻重算该高度。idle / 正在搜索 / 失败 / 去登录也走同一块剩余高度。详情区保持能返回列表。
- 按当前列表区高度，计算一页能完整放下的双列行数，至少 1 行（2 张卡）。一页内的卡片必须完整露出：封面、当时有的标题、主按钮「同款」，禁止再出现半截封面。封面比例可以按可用高度调整，但同一页卡片等高，仍是双列。缺字段仍省略，不填假数据。查询说明「当前按…搜索」固定在列表区顶部，分页固定在列表区底部。一页用分页切换，卡片网格里不再出一套竖向滚动条。
- 仅对已经取回的这一批条目分页，翻页不重新搜索、不向平台再取。「上一页」到上一页，第一页禁用；「下一页」到下一页，最后一页禁用；「第 x / y 页」只展示当前页码，不必再做跳页输入。工具栏「找到 N 条」是这一批总数，翻页不变。全部条目在当前高度下一页能放下时，隐藏「上一页」「下一页」「第 x / y 页」，不要空壳分页。每页条数等于当前能完整放下的卡片数（偶数，至少 2）。窗口变高可一页变多，变矮变少；尽量保住变化前该页第一张，若页码越界则落到最后一页。最后一页可以不满。从一张卡点进详情再点「返回列表」，回到原来那一页、同一条仍在。点整张卡进详情；点「同款」仍是建项目并进入。换分类、换关键词、换平台重新搜索后，从第 1 页展示新结果。本条不改平台「加载更多」，仍只展示已经取回的这一批。B 站不走这套列表。
