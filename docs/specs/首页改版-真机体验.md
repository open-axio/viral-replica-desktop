# 首页改版真机体验

## 需求

试用安装包已经能打开改版首页，但真机上有四条体验问题，要一并修掉。

1. 「软件更新」弹层点「确认并继续」没有用，只能退出再打开。截图里同时出现互斥文案：一边说 macOS 打包版不能原地改写、请到 Releases 下载，一边又说会备份、替换代码并自动重启；「取消 / 确认并继续」和「关闭 / 检查更新 / 立即更新」叠在一起。更严重的是：检查更新对照的是 `main` 上的清单。试用包当前版本是 `20261123-1220`，弹层把 `main` 上更早的 `20261118-1715` 标成「有新版本」。如果真的更新成功，会把首页改版覆盖回旧代码。仓库当时也还没有 GitHub Releases 安装包，「请到 Releases 下载」是空的。
2. 每次切换「抖音 / 小红书 / B站」Tab，内嵌区都会变成空白，并显示「正在确认登录状态…」，即使这一次使用里刚刚已经确认过登录。
3. 页面滚动不跟手。
4. 平台页嵌在首页里之后，出现两套滚动：鼠标在外层滚工作台，在内层滚平台页，要来回找落点。

本切片只改这四条。不扩大到新功能，不改登录判定松紧，不合并 PR，不发正式版。

## 设计

### 1. 软件更新

- 版本号按现有格式 `YYYYMMDD-HHMM` 比较。远端版本不高于当前版本时，不提示「有新版本」，不出现「立即更新」，检查结果按「当前已是可用版本」处理。试用分支包对上 `main` 的旧清单，必须走这条，不能引导用户「升级」到旧代码。
- 当前安装不能原地更新时（macOS 打包版改应用内文件会破坏签名，或程序目录只读）：不要再给出「立即更新」「确认并继续」这种走不通的按钮。弹层只说清：可以继续用当前这个安装包；应用内不能改程序代码。主按钮是「关闭」，点了必须马上关掉弹层，回到正在用的页面。
- 不要再写「请到 Releases 下载新版安装包」，除非当时仓库里真的有可下载的正式安装包。没有正式包时，不给空链接，也不把试用 CI 产物当成正式发布。
- 能原地更新时（例如源码目录或 Windows 安装目录可写，且远端版本确实更高）：「立即更新」先出确认文案，确认后必须开始备份、替换并自动重启；失败要把原因留在弹层里，不能无响应。进入确认时，隐藏或停用「立即更新」，避免两排按钮和两段互斥说明同时出现。
- 「确认并继续」和「立即更新」只要还能点，就必须有看得见的结果：开始更新，或明确说明不能更新并收起确认区。不允许点了之后既不更新、也不关掉、也不改文案。

### 2. 切换平台 Tab

保留「判定不准时宁可当成未登录」，以及未确认前不把平台登录页露出来。改的是确认过程的呈现，不是判定规则。

- 本次打开应用后，按平台记住最近一次已经确认的结果（已登录 / 未登录）。
- 切到一个本次已经确认「已登录」的平台：内嵌区保持可见，直接加载该平台内容；工具条可以显示「加载中…」，但不得再铺一层空白的「正在确认登录状态…」。加载期间如果判定变成明确登录墙，再收起内容、改成空态和「去登录」。
- 切到一个本次已经确认「未登录」的平台：直接出空态和「去登录」，不要先闪确认中的空白页。
- 本次还没确认过的平台，或刚启动后第一次进入：仍可显示「正在确认登录状态…」，确认前不露出登录墙。
- 同一次使用里来回切 Tab，不应每次都像重新登录一样要等空白确认。

### 3. 滚动：一屏一层

首页在桌面版展示「找同行的爆款」时，不能有两套滚动条抢鼠标。

- 顶栏、平台 Tab、搜索、行业词、分享链接这一组操作区固定在窗口上半，不随平台内容滚动。
- 内嵌区占满剩下的窗口高度，只有这一块滚动平台内容。最近项目放在这组操作区附近或内嵌区下方的固定位置，不要为了看 feed 还要先滚动工作台外层。
- 鼠标在内嵌区时只滚动平台页；在上方操作区时不滚动平台页，也不再滚走整页把内嵌区带跑。
- 滚动要跟手。窗口缩放、滚动和对位时，原生内嵌视图必须贴着占位区，不能抖动、错位或把操作区挡住。

## 任务清单

- [ ] T1 软件更新弹层不再提供走不通的更新，也不把更旧的 `main` 清单当成新版本。验收：用当前试用包的版本号对照一份更旧的远端清单，打开「软件更新」不得出现「有新版本」和「立即更新」；在不能原地更新的环境里，即使有更高版本，也不得出现「立即更新」或「确认并继续」，点「关闭」必须立刻回到原页面。有自动化用例覆盖「远端版本更低或相同不提示新版本」和「不能原地更新时不出现应用内更新按钮」。
- [ ] T2 同一使用过程中切换已确认过的平台 Tab，不再出现空白「正在确认登录状态…」。验收：已登录的平台之间来回切，内嵌区保持可见（可显示加载中）；已确认未登录的平台直接出「去登录」；本轮未确认过的平台仍先确认、不露登录墙。自动化用例覆盖这三种状态，并回归原有登录空态和去登录用例。
- [ ] T3 首页改为上区固定、内嵌区占满剩余高度，只有平台页滚动。验收：窗口内不再出现「工作台外层和平台页抢滚动」；滚动跟手；缩放和滚动后内嵌区仍对齐占位，不挡操作区。能自动化的部分（布局：操作区不随页面滚动、内嵌区高度随窗口剩余空间变化）要有用例；跟手和真机对位在说明里记录是否已在桌面会话验证，没有则写 `not run — 原因`。
