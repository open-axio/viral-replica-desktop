# 首页改版 Spec

> spec-first：先写需求→设计→任务清单再写代码；写完即开工，不等审批，项目负责人可随时异步查看。
> 进度以勾选任务清单为准（卡点与风险记在 docs/activeContext.md，不重复）；
> 开工后正文原则上冻结，只更新「任务清单」勾选与「状态」节；确需改需求或设计，注明原因，不静默改写。

## 需求（Requirements）

- 背景：当前首页上部常驻大段产品介绍（`#emptyState .home-hero`）和四步说明，主舞台被顶下去。「找同行的爆款」只提供平台 Tab、搜索和粘贴链接；桌面版一点「去找爆款」或「打开」就会新开独立浏览窗口（`build/browse.js` 里的 `BrowserWindow`）。登录态其实已经记在独立会话分区 `persist:find-viral`，但首页不会据此直接铺出该平台内容。用户回家页是为了刷同行爆款，不是先读完介绍。
- 目标：首页主舞台改为「找同行的爆款」。已登录的抖音、小红书、B 站，内容直接铺在对应 Tab 下面，用 Tab 切换；搜索、行业词都在这片区域里完成，不再新开窗口。没登录才新开一页去登录，登完回到这个 Tab 出内容。顶部介绍不再常驻，但不删除：收到固定入口里，文案收短，并补上人性化引导。
- 范围：本切片只改桌面版首页与「找同行的爆款」浏览承载。项目内四阶段流程（上传 / 免费拆解 / 内容拆解 / 复刻成片）不改。用浏览器打开工作台时，没有内置会话，不承诺内嵌登录态，保持现有「新标签页打开搜索」行为。
- 验收标准：
  - [ ] 打开首页，第一屏主内容是「找同行的爆款」，看不到常驻的大标题介绍和四步列表。
  - [ ] 顶栏有固定入口「这是什么」。点开能看到产品介绍（文案按本规格「介绍文案」），介绍没有被删掉。
  - [ ] 本机第一次打开，或还没有任何项目时，自动弹出一次该介绍，可跳过；跳过或关闭后不再自动挡路，仍可从「这是什么」再次打开。
  - [ ] 桌面版、某平台在 `persist:find-viral` 里已登录时：切到该 Tab，平台已登录内容直接出现在 Tab 下方，不新开窗口。
  - [ ] 在该区域搜索或点行业词，搜索结果仍在首页这片区域里更新，主窗口保持在前台，不再创建新的浏览窗口。
  - [ ] 某平台未登录时：该 Tab 下方是空态（说明登录后能直接刷到平时看的内容）和「去登录」。点「去登录」才新开登录页；登录成功后该页关闭，回到首页对应 Tab 并出内容，同时出现一句短确认（如「已登录抖音，下面是你的内容」）。
  - [ ] 内嵌区域仍能后退、刷新，并保留「同款复刻」：打开一条正在播放的视频后点它，能按现有逻辑建项目并进入该项目。
  - [ ] 粘贴分享链接仍可用；「最近的项目」仍在首页，位置在找爆款区域下方。没有项目时，保留「自己放一条视频进来」作为次要入口，不再用整块主 CTA 占顶部。
  - [ ] 看中内容时有轻提示「点同款，会自动拆给你看」（未完成过同款、或该提示未被用户关掉前出现；关掉后不再烦）。
  - [ ] 继续遵守现有红线：不调平台签名接口、不伪造身份、不在后台批量抓取；只处理用户正在看的这一页。

## 设计（Design）

- 方案：
  1. **首页结构**：去掉常驻 `.home-hero`。自上而下为：顶栏（品牌、这是什么、原有设置等）→ 找同行的爆款（标题 + 平台 Tab + 搜索/行业词/分享链接 + **平台内容区**）→ 次要入口「自己放一条视频进来」→ 最近的项目。
  2. **介绍入口**：顶栏固定「这是什么」，打开模态或侧栏，不跳走首页。首次启动或项目数为 0 时自动打开一次，用本机标记记录「已看过自动介绍」。介绍关闭后，首页立刻露出找爆款主舞台。
  3. **介绍文案**（按此写，不另起营销长文）：
     - 标题：看懂一条爆款，再换成你的店、你的人
     - 三句话：先在这里看同行怎么拍；拆解在你电脑上免费完成，不用填 Key；想照着做，再换成你的人和商品出片。
     - 补充一句：视频只留在这台电脑上，不会上传到任何服务器。
     - 四步说明（放进介绍里，不放首页主舞台）：① 放进对标视频（免费）② 免费拆解：台词、镜头、拍摄方式（免费）③ 内容拆解（要 Key）④ 复刻成片（要 Key）。
  4. **平台内容区（桌面版）**：把现在独立浏览窗口里的 `WebContentsView` 嵌进首页当前 Tab 下方，**复用**已有会话分区 `persist:find-viral`（不要另开分区，否则用户已经登过的号会丢）。三个 Tab 共用这一块区域，切 Tab 时在同一视图里加载对应平台首页或当前搜索结果。搜索框、行业词、前进后退刷新、「同款复刻」都挂在这片区域的工具条上，不再为搜索新建 `BrowserWindow`。
  5. **登录态**：今天没有现成的「是否已登录」接口，不能编造平台私有接口去查。实现上只根据该分区里打开平台首页后的页面结果来判断（例如一直停在登录/扫码页则视为未登录；进入平台首页或推荐/关注内容则视为已登录）。判定不准时，宁可当成未登录，让用户走「去登录」，不要把登录墙当成已登录信息流。三个平台的判定规则要分别验证，写进实现注释或测试说明，不要三家套同一套选择器。
  6. **未登录**：Tab 下只显示说明 +「去登录」，不自动弹登录窗。点「去登录」再新开登录页（可用单独小窗，只承担登录）。登录成功后关闭该页，首页对应 Tab 刷新为已登录内容，并给一句短确认。登录页不要承担搜索和同款（那些回到首页区域做）。
  7. **已登录默认内容**：无搜索词时，Tab 下直接展示该平台登录后的默认内容（抖音首页、小红书发现/推荐、B 站首页，以登录后平台自己给出的首页为准，不自造信息流）。有搜索词或点了行业词，则在同一区域打开该平台搜索结果。城市仍可与关键词拼在一起搜，逻辑与现在一致。
  8. **引导**：未登录空态写明「登录后能直接刷到你平时看的内容，不用再复制链接」。已登录且用户还没成功做过「同款复刻」时，在工具条或卡片旁给一次可关闭的轻提示：「看中了就点同款，会自动拆给你看」。登录成功仅提示一次。
  9. **分享链接**：仍在找爆款区域保留。已登录时，打开链接也在首页内容区里完成，不新开浏览窗口；未登录则先走「去登录」，登完再打开该链接。
  10. **工具条最低配置**（内容区内）：后退、前进、刷新、当前平台 Tab、搜索、状态提示、「同款复刻」。同款复刻的导入、建项目、读评论、下载正在播放的视频，沿用 `build/browse.js` 现有逻辑，不另做抓取。
- 涉及模块：`workbench/web/index.html`、`workbench/web/flow.js`、`workbench/web/style.css`、`build/browse.js`、`build/browse.html`、`build/main.js`（窗口与视图挂载）。
- 备选方案与取舍：
  - 否决「介绍整段删除」：用户明确要求保留，只是不再常驻，改入口 + 首次自动出现一次。
  - 否决「搜索仍开独立大窗、只把登录态同步回首页」：这解决不了「不要新起一页」的目标。
  - 否决「三个平台各开一个常驻隐藏窗口预加载」：费资源，也更容易被平台当成异常浏览；改为当前 Tab 加载，切走后再加载目标平台。
  - 若某平台页面无法稳定嵌进主窗口（空白、强制外跳、长期识别为不支持的浏览器）：该 Tab 显示失败说明和「重新登录 / 在登录页打开」，不要静默再弹出旧的大浏览窗。此事列为实现风险，先按内嵌做，真机验证三家后再决定是否为单一平台写降级，不在本规格里预先放弃内嵌。
  - 不在本切片做官网或浏览器版的内嵌登录信息流。

## 任务清单（Tasks）

- [x] T1 首页去掉常驻 `.home-hero`，主舞台改为「找同行的爆款」；顶栏加上「这是什么」，弹层采用本规格介绍文案与四步；无项目或首次打开自动弹出一次且可跳过。判定：冷启动打开首页，第一屏没有大标题介绍；点「这是什么」能打开同一份介绍；清掉「已看过自动介绍」标记后会再自动出现一次。
- [x] T2 桌面版将平台视图嵌进首页当前 Tab 下方，复用 `persist:find-viral`；切 Tab、搜索、点行业词都在该区域更新，不再为这些动作新建 `BrowserWindow`。判定：桌面版执行一次搜索后，用系统窗口列表或调试日志确认没有新的浏览窗口，主窗口内对应区域 URL 变为该平台搜索页。
- [ ] T3 按页面结果判断三个平台的登录态：已登录直接展示该平台默认内容；未登录只出空态和「去登录」，不自动弹窗。判定：在该会话分区清掉某平台登录后，对应 Tab 必出「去登录」；该平台保持登录时，切到 Tab 能直接看到已登录内容（真机，三家各走一遍）。
- [ ] T4 「去登录」新开登录页；登录成功后关闭，回到首页对应 Tab 展示内容，并出现一句短确认。判定：真机至少完整走通一家平台（优先抖音），另外两家若当时环境允许一并验证，否则在 activeContext 标明 `not run — 原因`。
- [ ] T5 内嵌区域的后退 / 前进 / 刷新 /「同款复刻」与现有浏览窗口行为一致；看中一条正在播放的视频，点同款能建项目并打开。判定：沿用现有导入路径跑通一条，项目能出现在「最近的项目」里。
- [ ] T6 落地引导与次要入口：未登录说明、同款轻提示（可关）、登录成功短确认、分享链接在已登录时也在内容区打开、介绍关闭后可见「自己放一条视频进来」和「最近的项目」。判定：按本规格验收标准逐项点验并记录。
- [x] T7 用浏览器打开工作台时，搜索仍走新标签页，界面不承诺「已登录内容直接铺在 Tab 下」。判定：非桌面环境点搜索只打开新标签，不出现桌面版内嵌内容区。
