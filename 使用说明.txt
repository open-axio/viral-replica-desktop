爆款复刻工作台 · 使用说明
================================

【状态】本说明对应 v1.3.0 起的新版安装包。v1.3.0 尚未发布，
       首次启动向导仍在开发中，暂时不要按本文安装。
       已发布的旧版（1.6GB 双文件夹版）用法见 Releases 页面上对应版本的说明。


一、安装
--------

macOS
  1. 下载 ViralReplica-1.3.0-arm64.dmg（M 系列芯片）
     或 ViralReplica-1.3.0-x64.dmg（Intel 芯片）
  2. 双击打开，把图标拖进「应用程序」
  3. 第一次打开：在「应用程序」里右键点图标 → 打开 → 再点一次「打开」
     （因为还没做苹果签名，直接双击会提示"来自身份不明的开发者"）

Windows
  1. 下载 ViralReplica-Setup-1.3.0.exe
  2. 双击运行，可以自己选安装位置
  3. 如果弹出蓝色的「Windows 已保护你的电脑」：
     点「更多信息」→「仍要运行」


二、第一次启动
--------------

安装包本身只有一百多 MB，真正干活的运行环境要在第一次启动时下载，
大约 650MB 到 2GB，取决于你选哪档识别精度。

  1. 选一个文件夹存数据和模型（建议留足 5GB 空间）
  2. 选识别精度：
       轻量   约 150MB  口播清楚的探店视频够用
       标准   约 500MB  推荐，日常带货探店都够
       高精度 约 1.5GB  语速快、有方言、背景音乐大的片子更稳
  3. 「用国内镜像下载」保持勾上，会快很多
  4. 等进度条走完。中途断网可以关掉重开，已经下好的不会重复下


三、怎么用
----------

  1. 把对标视频拖进去（mp4 / mov，建议 60 秒以内）

  2. 自动拆解 —— 这一步完全免费，不用填任何 Key
       · 逐词识别台词，可导出字幕文件
       · 自动切分镜头，出缩略图和时间轴
       · 认出每个镜头是实拍、AI 生成还是图文动画
     拆完可以直接导出报告、字幕和分镜图。到这里就够用的话，
     不用再往下走。

  3. 想做复刻，才需要填 Key
     界面会引导你选渠道。Key 只存在你电脑上，不会上传。
     从这一步开始调用大模型，会产生费用，每次花钱前都会先问你。

  4. 选角和商品 → 一镜一镜对照修改 → 生成成片


四、常见问题
------------

提示「安装不完整」
  安装包没装全，或被安全软件拦掉了一部分。重新下载安装一次。

下载运行环境卡住或失败
  关掉重开，已经下好的部分不会重复下载。
  确认「用国内镜像下载」是勾上的。

台词认不准
  设置里把识别精度换成「高精度」，会另外下载约 1.5GB。

想换电脑用
  把数据文件夹整个拷过去，在新电脑上装好软件后指向它即可。
  Key 要重新填一次。


五、你的东西存在哪
------------------

原片、素材、生成结果都在你第一步选的那个数据文件夹里。
Key 存在同一个文件夹的 console.env。
卸载软件不会删这些，想彻底清掉就把那个文件夹删了。
